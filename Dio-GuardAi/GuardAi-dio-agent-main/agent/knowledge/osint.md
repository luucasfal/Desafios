## Coleta de dados ##

Base de conhecimento que o agente consulta para o processo de coleta de informação(skill `penetration-test`). Define formas de coleta de dados de uma sistema, rede ou aplicação.

## OSINT

OSINT significa Open Source Intelligence ou inteligência de fontes abertas, ou seja, informações abertas na internet ao público.
